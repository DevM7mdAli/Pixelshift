Pixelshift is a set of image tools that run entirely in the browser. The repository separates its processing engine, Lit interface, and framework adapters so applications share behavior without sharing framework code.

## What it handles

| Tool                      | What it does                                                                     |
| ------------------------- | -------------------------------------------------------------------------------- |
| Image compressor          | Shrinks JPEG, PNG, and WebP while keeping the format; can aim for a target size  |
| Image resizer             | Exact pixels or a percentage, with an aspect lock and cover/contain/fill fitting |
| Image converter           | PNG, JPEG, WebP, GIF (first frame), and BMP to PNG, JPEG, or WebP                |
| Image cropper             | A draggable crop box with preset ratios or exact pixel values                    |
| Color picker              | Dominant palette plus any pixel, as HEX, RGB, and HSL                            |
| Image to Base64           | Data URLs with HTML, CSS, Markdown, and JSON snippets                            |
| Social media resizer      | Profile, cover, post, and story sizes for eight platforms                        |
| YouTube thumbnail resizer | 1280 × 720 under YouTube's 2 MB limit, previewed at feed sizes                   |
| Background remover        | Removes plain backgrounds from product shots, logos, and signatures              |

The studio puts every tool behind one tab bar. Each tool is also its own element, so you can embed only the ones you need. Inputs are limited to 25 MiB and 40 million pixels by default.

## Pick your integration

- Use `pixelshift-web-core` for vanilla JavaScript or any environment that supports custom elements.
- Use `pixelshift-react` for typed React components, events, and refs.
- Use `pixelshift-angular` for Angular inputs, outputs, and public methods.
- Use `pixelshift-vue` for Vue props, emits, and exposed methods.
- Use `pixelshift-core` when you need the processing functions without UI.

## Privacy by architecture

Files are decoded with browser APIs and encoded through canvas. There is no upload endpoint in the library, so image bytes remain on the user's device.
