## Requirements

Pixelshift needs a modern browser with custom elements, canvas, `Blob`, and either `createImageBitmap` or image decoding support.

## Install

For React:

```bash
pnpm add pixelshift-react
```

Render the studio to get every tool behind one tab bar:

```tsx
import { PixelshiftStudio } from "pixelshift-react";

export function Tools() {
  return (
    <PixelshiftStudio
      onProcessComplete={(event) => console.log(event.detail)}
      onProcessError={(event) => console.error(event.detail.error)}
    />
  );
}
```

Or render a single tool. Only the components you import are registered and bundled:

```tsx
import { ImageCompressor, type CompressionResult } from "pixelshift-react";

function handleComplete(event: CustomEvent<CompressionResult[]>) {
  for (const result of event.detail) {
    console.log(
      result.file.name,
      `${Math.round(result.savings * 100)}% smaller`,
    );
  }
}

export function Upload() {
  return (
    <ImageCompressor
      quality={0.75}
      targetSize={200 * 1024}
      multiple
      onProcessComplete={handleComplete}
    />
  );
}
```

Image results contain the processed `Blob`, a downloadable `File`, dimensions before and after, MIME types, byte sizes, and the processing time. Users can also download each result, or a whole batch as a ZIP file, from the element itself.

## Browser lifecycle

Pixelshift can be imported by server-rendered applications, but processing requires browser APIs. Render and call the components from client-side code after they have mounted.

See [Tools](/docs/tools) for each tool's options and [Framework adapters](/docs/frameworks) for complete React, Angular, and Vue examples. Repository contributors can continue with [Development](/docs/development).
