Every Pixelshift tool is a Lit custom element, and every framework adapter renders these same elements. This page covers what all of them have in common. [Tools](/docs/tools) lists what each one adds.

## Install and register

```bash
pnpm add pixelshift-web-core
```

Import the registration entry once in your browser application. It registers the studio and every tool:

```ts
import "pixelshift-web-core/define";
```

The elements are then available in HTML:

```html
<pixelshift-image-converter
  format="webp"
  quality="0.85"
  max-width="2400"
  max-height="2400"
  multiple
></pixelshift-image-converter>

<pixelshift-image-compressor target-size="200kb"></pixelshift-image-compressor>
```

### Register only what you use

The package root registers nothing by itself. Import a tool's `define` function to register just that element; bundlers drop every tool you do not import:

```ts
import { defineImageCompressor, defineImageCropper } from "pixelshift-web-core";

defineImageCompressor();
defineImageCropper();
```

| Function                    | Element                                        |
| --------------------------- | ---------------------------------------------- |
| `defineImageCompressor()`   | `<pixelshift-image-compressor>`                |
| `defineImageResizer()`      | `<pixelshift-image-resizer>`                   |
| `defineImageConverter()`    | `<pixelshift-image-converter>`                 |
| `defineImageCropper()`      | `<pixelshift-image-cropper>`                   |
| `defineColorPicker()`       | `<pixelshift-color-picker>`                    |
| `defineImageToBase64()`     | `<pixelshift-image-to-base64>`                 |
| `defineSocialResizer()`     | `<pixelshift-social-resizer>`                  |
| `defineYouTubeThumbnail()`  | `<pixelshift-youtube-thumbnail>`               |
| `defineBackgroundRemover()` | `<pixelshift-background-remover>`              |
| `defineStudio()`            | `<pixelshift-studio>` and every tool inside it |

Registration functions are idempotent and safe to call during server rendering; they do nothing when `customElements` is unavailable.

## Shared properties

| Property      | Attribute      | Default         | Purpose                                                           |
| ------------- | -------------- | --------------- | ----------------------------------------------------------------- |
| `disabled`    | `disabled`     | `false`         | Block all interaction                                             |
| `isDarkMode`  | `is-dark-mode` | `false`         | Switch to the dark palette                                        |
| `bare`        | `bare`         | `false`         | Drop the panel border, padding, and header to fit your own layout |
| `auto`        | `auto`         | `false`         | Process as soon as files arrive instead of waiting for the button |
| `heading`     | `heading`      | tool's title    | Replace the title                                                 |
| `description` | `description`  | tool's subtitle | Replace the subtitle                                              |

The color picker and the Base64 tool default `auto` to `true`.

Dark mode follows `is-dark-mode` rather than `prefers-color-scheme`: an element cannot see the host page's own theme state through its shadow root, so the page sets it explicitly.

## Getting files in

Users can drop files onto the dropzone, browse for them, or paste images from the clipboard while focus is inside the element. Selected files are listed with thumbnails and can be removed one by one.

To supply files from code, call `loadFiles()`. It behaves exactly like a drop, including the `files-selected` event and `auto` processing:

```ts
const compressor = document.querySelector("pixelshift-image-compressor");
compressor?.loadFiles(fileInput.files ?? []);
```

## Methods and getters

| Member             | Purpose                                                        |
| ------------------ | -------------------------------------------------------------- |
| `loadFiles(files)` | Replace the selection with a `FileList` or `File[]`            |
| `process()`        | Run the tool on every selected file; resolves with the results |
| `cancel()`         | Stop a running batch after the current file                    |
| `reset()`          | Clear files, results, and errors                               |
| `files`            | The selected files (read-only)                                 |
| `results`          | Results of the last completed run (read-only)                  |

`process()` resolves with an empty array when there are no files, the element is disabled, or a run is already in progress.

```ts
if (compressor) {
  const results = await compressor.process();
  console.log(results);
  compressor.reset();
}
```

## Events

All events bubble and cross the shadow-DOM boundary.

| Event              | Detail                                  |
| ------------------ | --------------------------------------- |
| `files-selected`   | `File[]`                                |
| `process-start`    | `File[]` about to be processed          |
| `process-complete` | the tool's results                      |
| `process-error`    | `{ file, error }`, once per failed file |

```ts
import type { ImageCompressorElement } from "pixelshift-web-core";

const compressor = document.querySelector<ImageCompressorElement>(
  "pixelshift-image-compressor",
);

compressor?.addEventListener("files-selected", (event) => {
  const files = (event as CustomEvent<File[]>).detail;
  console.log(`${files.length} files selected`);
});
```

Some tools add their own events, such as `crop-change` and `color-pick`; see [Tools](/docs/tools).

### Failures

A batch keeps going when one file fails. Each failure fires `process-error` and is listed in the element with the file name and the reason, and `process-complete` fires with the files that succeeded.

The image converter is the exception. It predates the other tools and stays fail-fast: one failed file rejects the whole batch, `process()` and its alias `convert()` resolve with `[]`, and it also fires its original `conversion-start`, `conversion-complete`, and `conversion-error` events.

## Theming

Colors, radii, and fonts are CSS custom properties. Custom properties inherit through the shadow root, so set them on the element or any ancestor:

```css
pixelshift-studio {
  --pixelshift-accent: #ff6838;
  --pixelshift-accent-content: #ffffff;
  --pixelshift-radius: 6px;
  --pixelshift-font-family: "IBM Plex Sans", sans-serif;
}

.dark pixelshift-studio {
  --pixelshift-accent: #caff45;
  --pixelshift-accent-content: #151614;
}
```

Overrides apply in both themes, so scope them to your own dark-mode selector when they should differ.

| Property                      | Purpose                                 |
| ----------------------------- | --------------------------------------- |
| `--pixelshift-surface`        | Panel background                        |
| `--pixelshift-surface-muted`  | Dropzone and preview backgrounds        |
| `--pixelshift-field`          | Input background                        |
| `--pixelshift-hover`          | Hover background                        |
| `--pixelshift-border`         | Subtle borders                          |
| `--pixelshift-border-strong`  | Input and button borders                |
| `--pixelshift-text`           | Primary text                            |
| `--pixelshift-text-muted`     | Labels and secondary text               |
| `--pixelshift-text-subtle`    | Hints and metadata                      |
| `--pixelshift-accent`         | Primary buttons and selected states     |
| `--pixelshift-accent-hover`   | Primary button hover                    |
| `--pixelshift-accent-content` | Text on the accent color                |
| `--pixelshift-focus`          | Focus outline                           |
| `--pixelshift-danger`         | Error text                              |
| `--pixelshift-danger-surface` | Error background                        |
| `--pixelshift-success`        | Savings and success text                |
| `--pixelshift-radius`         | Control corner radius (default `8px`)   |
| `--pixelshift-panel-radius`   | Panel corner radius (default `12px`)    |
| `--pixelshift-font-family`    | Text font (default: the system UI font) |
| `--pixelshift-font-mono`      | Code and color values                   |

For anything the tokens do not cover, style the exposed parts with `::part()`:

| Part       | Element                     |
| ---------- | --------------------------- |
| `panel`    | The outer container         |
| `heading`  | The title                   |
| `dropzone` | The file drop area          |
| `action`   | The primary action button   |
| `results`  | The result list             |
| `download` | Each result's download link |

```css
pixelshift-image-compressor::part(panel) {
  box-shadow: none;
}
```
